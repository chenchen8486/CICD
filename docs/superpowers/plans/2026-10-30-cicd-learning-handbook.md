# CI/CD 学习手册实施计划

> 执行要求：按任务顺序实施并逐项验证，不进行 Git 提交。

　　目标：制作一份面向算法与软件开发初学者的中文单文件 HTML 手册，使读者能够完成团队协作中的代码提交、查看与修改 CI 流水线、排查常见失败。

　　架构：使用原生 HTML、CSS、JavaScript，无运行时外部依赖。九个章节放在同一页面，左侧章节导航与右侧本章目录联动。流程图先生成 SVG，再内嵌到 HTML，保证离线显示和黑白打印。

　　技术：HTML5、CSS、原生 JavaScript、内嵌 SVG、D2 图形生成。

　　依据：用户在会话中确认的九章目录，以及参考项目 `D:/project/python_release_MV/LLM_learning` 的页面布局。

## 全局约束

- 正文自然段首行缩进两个全角空格，列表、表格和代码块不缩进。
- 使用黑白灰配色，避免彩色提示框、装饰性竖线和多余卡片。
- 重点内容优先用自然段、表格、代码与 SVG 图表达。
- 以 Python 项目和 GitLab CI/CD 为主要示例，真实截图来自 GitLab.com 公开项目。
- 示例必须可理解、语法有效，不能编造平台行为。
- 页面离线可用，支持桌面与移动端、键盘导航和打印。

## 重点复核

- 窄屏下目录不能遮挡正文，展开后可以关闭。
- 锚点跳转后标题不能被顶部阅读进度条遮挡。
- 无 JavaScript 时正文与 SVG 仍可阅读。
- 黑白打印时代码、表格与图示仍有足够对比度。
- 浏览器本地存储不可用时不影响阅读。
